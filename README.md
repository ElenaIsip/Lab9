# Алгоритм и блок-схема

Начало программы. Установка русской локали.

Ввод параметра R (радиус):

* Если введено не число или R ≤ 0 → Аварийное завершение (выход с ошибкой).

Ввод параметра a (внутренний параметр):

* Если введено не число, a ≤ 0 или a ≥ R → Аварийное завершение (выход с ошибкой).

Расчет границ экрана (холста): задаются переменные width и height (хотя в самом цикле они не используются, границы вычисляются как -R-2 до R+2).

Внешний цикл перебирает координату y (строки сверху вниз) от -R-2 до R+2:

Для каждой строки y:

* Внутренний цикл: перебор координаты x (символы слева направо) от -R-2 до R+2:

* Коррекция масштаба: вычисление real_y = y / 2.2 (сжатие по оси Y для компенсации вытянутости консольных символов).

Проверка 1 (Окружность):

* Вычисляется расстояние от центра (0,0) до точки (x, real_y).

* Если расстояние попадает в узкий диапазон [R - 0.5 ; R + 0.5], считается, что точка лежит на границе окружности (флаг is_circle = Истина).

Проверка 2 (Контур дельтоида):

* Вычисляются координаты "талии" фигуры: tx = R - a, ty = sqrt(R² - a²).

 Правая часть: если x находится между tx и R:

* Вычисляется уравнение прямой (верхней/нижней грани).

*  Если отклонение real_y от прямой меньше 0.6 → is_deltoid_edge = Истина.

Левая часть: если x находится между -R и tx:

* Вычисляется уравнение прямой.

* Если отклонение real_y от прямой меньше 0.6 → is_deltoid_edge = Истина.

Вывод символа в текущую точку (x, y):

* Если is_deltoid_edge (точка на контуре дельтоида) → вывести symbol.

* Иначе если is_circle (точка на окружности) → вывести точку ..

* Иначе (точка внутри или снаружи) → вывести пробел .

* Конец внутреннего цикла (перебор x).

Вывод символа перевода строки (переход на новую строку экрана).

Конец внешнего цикла (перебор y).

    int R, a;
    char symbol;

    printf("Введите радиус R: ");
    if (scanf("%d", &R) != 1 || R <= 0) return 1;

    printf("Введите параметр a: ");
    if (scanf("%d", &a) != 1 || a <= 0 || a >= R) return 1;

    while (getchar() != '\n');

    printf("Введите символ: ");
    scanf("%c", &symbol);

    int width = 2 * R + 4;
    int height = 2 * R + 4;

    printf("\n");

    for (int y = -R - 2; y <= R + 2; y++) {
        for (int x = -R - 2; x <= R + 2; x++) {
            double real_y = y / 2.2;

            double dist_to_center = sqrt(x * x + real_y * real_y);
            int is_circle = (dist_to_center >= R - 0.5 && dist_to_center <= R + 0.5);

            int is_deltoid_edge = 0;
            double tx = R - a;
            double ty = sqrt(R * R - a * a);

            if (x >= tx && x <= R) {
                double k = ty / (tx - R);
                double line_y = k * (x - R);
                if (fabs(real_y - line_y) < 0.6 || fabs(real_y + line_y) < 0.6) {
                    is_deltoid_edge = 1;
                }
            }

            if (x >= -R && x <= tx) {
                double k2 = ty / (tx + R);
                double line_y = k2 * (x + R);
                if (fabs(real_y - line_y) < 0.6 || fabs(real_y + line_y) < 0.6) {
                    is_deltoid_edge = 1;
                }
            }

            if (is_deltoid_edge) {
                putchar(symbol);
            }
            else if (is_circle) {
                putchar('.');
            }
            else {
                putchar(' ');
            }
        }
        putchar('\n');
    }

    return 0;
